# Human-facing work

Before changing the public story, read the pinned adapter in `.content-system/` and use the exact helper commit recorded there.

For README, product, visual, or marketing work, load the pinned helper's content research, brand direction, README playbook, image guide, and README contract. Read `docs/content-system-assets/IMAGE_NOTES.md` before changing a committed visual. Keep claims tied to repository evidence, label experiments and plans, and never add credentials or private source records.

Narrative README banners must use ChatGPT's built-in image generation workflow, carry one exact title and one exact subtitle supplied verbatim in the prompt, and record the prompt intent, alt text, dimensions, crop behavior, rejection conditions, review decision, and final hash. Do not replace a requested narrative banner with a hand-authored SVG or a generic diagram. Technical diagrams may exist separately when they explain a distinct mechanism.

Use the target visual contract in `.content-system/visual-style.json` and keep the anime-inspired maintainer-and-robot continuity across related assets. Reject a candidate that loses the human relationship, becomes a provider dashboard, adds unsupported live claims, or makes the price/supply/evidence trade-off unreadable.
